# Project Summary for Resume / GitHub

## Recommended repository name

**cifar10-cats-dogs-cnn-benchmark**

Alternative names:
- `pytorch-cifar10-binary-image-classifier`

- `cats-dogs-cnn-hyperparameter-study`

## GitHub description

PyTorch CNN benchmark for binary cats-vs-dogs classification on CIFAR-10 with train/validation/test splits, checkpointing, hyperparameter search, training-curve visualization, and ANN baseline comparison.

## Resume bullet

- Built a modular PyTorch image-classification benchmark for CIFAR-10 cats-vs-dogs, implementing CNN and ANN architectures, reproducible train/validation/test splitting, checkpointing, CSV metric logging, and hyperparameter sweeps across learning rate and batch size.
- Evaluated architecture tradeoffs using train/validation curves and held-out test accuracy, comparing CNN spatial feature learning against a flattened two-layer ANN baseline.

## LinkedIn project description

Converted a cats-vs-dogs image classification lab into a production-style PyTorch project. The repo includes reusable data loaders, CNN/ANN model classes, training and evaluation scripts, checkpointing, metric logging, hyperparameter experiments, and visualization of overfitting/underfitting through train-vs-validation curves.

This project demonstrates core ML engineering skills: model training loops, validation methodology, reproducibility, experiment organization, and performance analysis.
